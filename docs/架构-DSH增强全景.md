# 架构 · DSH 增强全景

> 一套可复刻的 **DSH（DeepSeek Harness）增强装配**的公开说明。
> 安装与件集口径照实整理；**不含任何凭据、账号、会话数据与个人化配置**。

---

## 一、总体分层

```
┌─ 体验层 ── 皮肤／动态壁纸／透明参数／桌宠／执行轨迹可视化（可选） ─┐
│                                                                  │
├─ 增强层 ── 38 个插件组成的一体化 agent 工作台                     │
│            ＋ 6 个本地扩展件（带源码，可自行修改）                 │
│                                                                  │
├─ 内核机制层 ── 多智能体预设（席位）／跨会话记忆／多模型路由        │
│                ／MCP 工具接入／技能管理                            │
│                                                                  │
└─ 本体 ── DSH（cordis 内核；web profile ＋ headless profile 双栈） ┘
```

---

## 二、增强层

**38 个插件**（npm 公开生态）：插件市场、任务看板、多会话管理（回溯／分支／导入）、浏览器操作、文件工作区、PPT 生成、交付质量闸、性能观测、SSH、手机远程访问、桌宠……

**6 个本地扩展件**（源码随包）：

| 件 | 说明 |
|---|---|
| `@文件引用` | 输入框里 `@路径` 引用工作区文件 |
| `预算表` | token 用量按官方价折算的悬浮胶囊 |
| `底部坞` | 屏幕底部可开合面板，内嵌终端 |
| `设置作用域垫片` | 兼容层，配合 0.4.4 版插件族 |
| `网页文件预览` | 界面内直接播放视频／查看日志 |
| `工作线路` | 右侧悬浮的实时执行轨迹面板（PCB 走线风） |

**体验层**：皮肤 ＋ 动态壁纸 ＋ 玻璃透明参数 ＋ 底部桌宠（均可选）。

---

## 三、内核机制（升级线）

- **预设／席位制**——多智能体预设按会话选择；**各席有各自档案与记忆空间**；记忆跨会话、跨项目保留——「席换到哪，读的就是哪席的记忆空间」。切换模型、切换对话方式均不影响记忆归属。
- **记忆系统**——宿主／客户端两层 ＋「来源接入」（摘要＋指针，原文不动）；记忆可修剪、可改档；只读复核时记录亦受控。
- **多模型路由**——按席／按档位配模型；故障回退与成本护栏。
- **MCP 工具接入**——外部能力以标准协议即插即用，两步接入（登记＋授权）。
- **技能管理**——多席共享同一技能目录；技能即知识包（含使用规程）。禁用＝移出扫描根。
- **协作可见性**——实时日志 ＋ Web UI 直播 ＋「工作线路」轨迹面板。

## 四、治理与发行

**治理**（详见 [常态工作流.md](常态工作流.md)）：双层治理（治理索引＋规程文件）、派单规程、验收门（判死线≥15 分钟；探针必须带真工件）。

**发版四件套**（可复刻的发行线）：

| 件 | 职责 |
|---|---|
| `manifest.json` | 件集清单＋逐件 sha256＋集指纹 |
| `scan-artifacts.mjs` | 件集实取（口径＝三源并集：`link:` 依赖 ∪ bundles ∪ patch 绝对路径挂载） |
| `verify-release.mjs` | 守卫校验（改动一字节→红 exit 1；复原→绿 exit 0） |
| `pack-release.mjs` | 打包对账（逐条含 sha256 全绿） |
| `发行台账` | 一行一次发行（版本／日期／件集摘要／快照点／验收人）；回退＝追「回退行」 |

**排除面 denylist（代码化，扫描/校验/打包三处同一规则）**：目录 `node_modules`、`.git`、`evidence`；文件 `.bak-*`、`*.tsbuildinfo`、`_基线*`（＝不可复刻／重跑即变／环境态，非「件的源代码或配置」）。

**一次真实发行（示例，2026-10-12 · v1.0.2）**：家制件 19 件／771 文件／22,076,594 B；守卫 19/19 全绿；打包对账 771/771 逐条含 sha256 全绿；包内 manifest 副本逐字节相同；zip 附 sha256 指纹。

## 五、复刻（最短路径）

1. **准备**：Windows 10/11；Node.js 22+；`npm install -g pnpm`；
2. **装本体**：`npm install @deepseek-ai/dsh@0.2.0-rc.2`，首启并按提示配置你自己的 API Key（费用自理）；
3. **部署增强包**：解压后运行 `setup.ps1`（自动链接本地扩展件、铺 profile 与皮肤参数）；
4. **按需配置**：预设／记忆／路由／技能，运行 web 或 headless profile。

> 增强包**不含**：任何凭据、账号、会话历史、任务数据、个人化配置、开发测试目录与截图。
