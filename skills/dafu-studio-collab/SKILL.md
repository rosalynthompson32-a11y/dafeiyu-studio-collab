# 大肥鱼工作室协作工作流（长期记忆）

## 一、工作区约定
- 工作根目录：`D:\大肥鱼工作室`
- 每个任务必须在根目录下创建**下级文件夹**：`D:\大肥鱼工作室\<任务名>\`
- 所有任务产出文件（代码、文档、HTML 等）都放在该任务的文件夹内，禁止散落在根目录或 D 盘其他地方。
- 已确认：`D:\大肥鱼工作室` 已存在（2026-08-24 确认）。

## 二、协作流程（固定三步）
1. **我完成任务**：按用户要求完成工作并产出文件到任务文件夹。
2. **我自检（初审）**：自己检查产出，在 `_实时日志.md` 写一行「## HH:MM 自检完成,初审交由监工 Claude」。
3. **交由监工终审**：成果交到监工 Claude 手上复核验收，通过后由监工向用户汇报。

> 2026-08-24 定案：**初审交给 dsh 自己，终审由监工 Claude 做**。原先"调用终端 claude CLI 初审"的环节已停用——原因：headless 模式下 pwsh 起 claude 子进程永久挂起（21:14 卡死 20+ 分钟），且独立 claude 进程与监工会话无通信通道、结果无人接收。

## 三、自检要求
- 自检必须真实：读一遍产出文件，逐项核对任务要求，有 bug 就修，修完再查。
- 自检结论写进 `_实时日志.md`（一行 `## HH:MM 自检完成,初审交由监工 Claude`）。
- **不要**用 pwsh 起 claude 子进程、**不要**用 powershell -NoProfile 包装工具调用（中文/长文本会解析失败）。

## 四、角色
- 用户：最终验收人（唯一人类）。
- 终端 Claude Code：监工 / 终审者。
- 我（DSH 助手）：执行者，负责产出、自检与汇报。
